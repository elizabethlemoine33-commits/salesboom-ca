Do not use: --muted (#5A6E8A) for body text on --bg-alt (#F3F5F9). The contrast is 3.6:1 — fails WCAG AA for normal text. Use --text-2 (#3A4F68) instead, which passes at 5.0:1.

FAQ accordion (HTML)
Is Salesboom.ca data stored in Canada? ▾
Yes. All Salesboom.ca customer data is stored exclusively on servers located in Canada, ensuring compliance with Canadian privacy law and immunity from the US CLOUD Act.

Native <details>/<summary> — no JavaScript. Keyboard accessible. :focus-visible ring required on summary. Pairs with FAQPage JSON-LD schema.

At-a-glance / citability block
At a glance
  • → Salesboom has been a Canadian-owned enterprise CRM since 2003.
  • → All customer data is stored in Canada, outside CLOUD Act jurisdiction.
  • → Used by 7,000+ organisations across 169 countries.

Required on every page — first content block after the hero. Blue left border (--blue). 3–5 bullet facts. This is the primary GEO citability signal.

salesboom.com vs salesboom.ca

What changed in the proposed design and why. Every change is documented here so it can be referenced in the proposal or implemented by a developer without ambiguity.

Element salesboom.com (current) salesboom.ca (proposed)
Body font Verdana/Tahoma, 11–12px DM Sans, 16px minimum body
Display font Ubuntu/Titillium (newer layer), no structured hierarchy Fraunces (serif display, 700 roman + 300 italic)
CTA button colour Orange (#FF5E00, #F6831D) — brand accent used for actions Green (#00783C) — orange reserved for accents only
Primary blue #003f80, #0d4986 (multiple slightly different values) #003C78 — single token, consistent across all usage
CSS architecture No CSS custom properties — all hardcoded hex values Token-based system (--blue, --orange, --green, --navy)
Heading hierarchy No consistent semantic hierarchy; h3/h4 used inconsistently Strict h1 → h2 → h3, no skips, WCAG 1.3.1 compliant
Keyboard navigation No visible focus states on interactive elements :focus-visible rings on all a, button, summary, [tabindex]
FAQ structure No FAQ section <details>/<summary> accordion + FAQPage JSON-LD schema
Structured data No JSON-LD of any kind Organization + WebSite + WebPage + FAQPage @graph
Citability block No at-a-glance or summary structure At-a-glance block on every page (primary GEO signal)
Services layout Visual grid, no semantic list markup <ol> with <li class="service-card"> — ordered, scannable
CEO quote Styled text, no semantic markup <blockquote cite="…"> with <cite> attribution
WCAG status Multiple AA failures (contrast, font size, heading skip, scope) Passes WCAG 2.1 AA across all tested combinations
GEO score ~37/100 (estimated) 87+ / 100 (deployed with schema)

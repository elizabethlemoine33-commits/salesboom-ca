What we found on salesboom.com

Before proposing anything, we audited the current site against modern accessibility standards and Generative Engine Optimisation (GEO) criteria — the same criteria that determine how AI-powered search engines like Google AI Overviews, Bing Copilot, and Perplexity cite and rank pages.

The current site was built for a different era of the web. It has strengths — a clear brand identity, a genuine differentiation story, and a large product portfolio — but several structural issues limit how it performs with both human visitors and AI search engines today.

Accessibility — WCAG 2.1 AA failures
Body text as small as 11–12px throughout. CTA buttons at contrast ratios below 3:1. No visible keyboard focus states. Table-based layout in sections where modern HTML semantics are required. These aren't visual preferences — they're compliance failures that also disadvantage search ranking.
GEO — No structured data
No JSON-LD schema of any kind: no Organization, no FAQPage, no WebPage. When an AI engine encounters a query about Canadian enterprise CRM or data sovereignty, it has no machine-readable signal to extract from salesboom.com. The content is present; the markup that makes it citable is not.
GEO — No FAQ or citability structure
No FAQ sections, no comparison tables with structured markup, no definition blocks for novel terms like "data sovereignty" or "A2A." AI engines cite pages that answer questions directly — the current site doesn't answer questions in a crawlable structure.
Opportunity — The differentiation story is strong
The CLOUD Act / data sovereignty narrative is genuinely differentiated in the Canadian enterprise CRM market and is exactly the kind of content AI engines will cite when Canadian businesses search for "US CLOUD Act CRM risk" or "data sovereignty enterprise software Canada." The story is there. It just needs to be structured correctly.

What we're proposing

Three interconnected workstreams, each building on the last:

1 — Brand alignment + accessibility
Extract the brand system from the logo and establish a token-based design language: blue for structure, orange for headlines, green for all CTAs. Apply WCAG 2.1 AA compliance across every text and contrast combination. The result is a brand guide that can govern every future page, component, and campaign — and a site that passes accessibility audits by design, not by retrofit.
2 — GEO/AEO architecture
Structure the content so AI engines can extract and cite it: FAQPage schema, Organization schema, an at-a-glance summary block, semantic heading hierarchy, proper blockquote markup for CEO quotes, and ordered lists where sequence carries meaning. The goal is to make salesboom.ca the page an AI engine cites when someone asks about Canadian enterprise CRM or CLOUD Act alternatives.
3 — Homepage redesign (this demo)
A working demonstration of the above, built and deployed: the demo in this package is not a mockup. It is a live, accessible, GEO-optimised homepage implementation using the brand system we extracted. Every section, component, and font choice is documented in the brand guide. The GEO audit scores the result.

The GEO score — before and after

GEO (Generative Engine Optimisation) scores how well a page performs with AI-powered search engines across five dimensions: crawler accessibility, citability signals, technical SEO, schema markup, and brand authority. The current salesboom.com scores 66/100. The proposed design scores 87 on a deployed URL with full schema implementation.
